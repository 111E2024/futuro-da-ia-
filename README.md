# 🧮 Matemática e sua Importância

Um projeto web interativo desenvolvido para apresentar, de forma simples e dinâmica, a importância da matemática na formação dos alunos e no cotidiano.

## 📚 Sobre o projeto

A matemática está presente em diversas situações do nosso dia a dia e contribui para o desenvolvimento de habilidades como raciocínio lógico, pensamento crítico, resolução de problemas e tomada de decisões.

Este projeto apresenta um pequeno quiz interativo no qual o usuário responde perguntas relacionadas à importância da matemática na educação. Após cada resposta, é apresentada uma reflexão sobre o tema.

## ✨ Funcionalidades

* 📖 Perguntas sobre a importância da matemática;
* 💭 Reflexões após cada resposta;
* 🖱️ Botões interativos;
* 🎨 Interface com cores em tons de rosa claro, branco e amarelo pastel;
* 📱 Layout simples e responsivo;
* 🧠 Abordagem educativa e reflexiva.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da página;
* **CSS3** — estilização e design;
* **JavaScript** — funcionamento do quiz e interação com o usuário.

## 🎯 Objetivo

O principal objetivo do projeto é mostrar que a matemática não se resume apenas a cálculos e fórmulas. Seu aprendizado também contribui para o desenvolvimento de habilidades que podem ser utilizadas na escola, na vida cotidiana e no futuro profissional.

## 📂 Estrutura do projeto

```text
📁 projeto
├── 📄 index.html
├── 📄 style.css
└── 📄 script.js
```

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Responda às perguntas e explore o quiz.

## 🎨 Design

A interface utiliza uma paleta de cores suaves, com:

* 🌸 Rosa claro;
* 🤍 Branco;
* 💛 Amarelo pastel.

O objetivo é criar uma experiência visual agradável, leve e acessível.

## 👩‍💻 Autoria

Projeto desenvolvido como atividade educacional para explorar o uso de **HTML, CSS e JavaScript**, utilizando a programação como ferramenta para apresentar conhecimentos sobre matemática.
